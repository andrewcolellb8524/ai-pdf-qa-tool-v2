## What Is AI PDF Assistant?

AI PDF Assistant is a single-file web app that lets you interact with PDF files using natural-language questions. Load a document, let the application examine its contents, and find information without scanning each page manually.

It is suited to document review, studying, and reference tasks where summaries, translations, and context-aware searches make research faster. The responsive interface is centered on the loaded document, supports different screen sizes, and can be used offline.

---

## Capabilities

- Import and process PDF documents within the browser
- Ask questions about the information contained in a PDF
- Automatically collect PDF text and metadata
- Produce summaries and explanations for lengthy sections
- Find search terms together with their surrounding context
- Translate document content into Spanish
- Choose between light and dark display themes
- Preserve conversations and provide chat export support
- Use an accessible, responsive interface contained in one file
- Continue working offline after the application has loaded

## Using the Application

1. Start AI PDF Assistant in your browser.
2. Upload a PDF, or open the sample document when one is provided.
3. Enter a question about the file. For example:
   - "Summarize this PDF"
   - "Where does it mention pricing?"
   - "Translate this section into Spanish"
4. Inspect the extracted text, document metadata, and answers in the chat interface.
5. Return to the conversation later or export it from the saved history.

A common review sequence looks like this:

- Load a document
- Submit an initial question
- Continue with follow-up prompts
- Locate important terms
- Export the conversation when complete

## Browser Storage and Settings

The application uses browser `localStorage` to retain chat history and associated session information. Theme selection and other application settings are controlled from within the interface.

To start over, clear the site's stored data in your browser or delete the `localStorage` records associated with the repository domain.

Stored application information can include:

- Persistent chat history
- Selected theme preference
- Session information for loaded documents

## Frequently Asked Questions

**What is the update process?**  
Download the newest build from the project page, then replace the existing copy with that version.

**How is my chat history stored?**  
Conversations are saved in your browser through `localStorage`.

**Does the app work without an internet connection?**  
Yes. Once loaded in the browser, the application is designed to operate offline.

**How should I troubleshoot a PDF that will not load?**  
Try another PDF, reload the page, or remove the stored browser data if the current session is no longer behaving correctly.

**Are light and dark themes available?**  
Yes. You can switch between the application's light and dark themes.
